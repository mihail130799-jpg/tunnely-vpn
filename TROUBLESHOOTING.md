# Частые проблемы

## У клиента

| Симптом | Причина и решение |
|---|---|
| «Нет связи с сервером подписки» | Панель недоступна или ссылка неверна. Проверить ссылку в браузере; на сервере — что порт панели открыт. |
| «Доступ к подписке запрещён (403/401)» | Подписка истекла или отключена в панели. |
| «Сервер не отвечает» при зелёном туннеле | Туннель поднят, но сервер отклоняет подключение. Выбрать другой сервер или «Авто». Для владельца: см. «REALITY authentication failed» ниже. |
| «Чтобы подключиться, разрешите Tunnely создать VPN» | В системном окне нажали «Отмена». Нажать на туннель ещё раз и выбрать «ОК». |
| VPN отключается сам | Включён другой VPN (Android допускает только один) или прошивка «убивает» фоновые приложения: Настройки → Батарея → Tunnely → «Без ограничений». |
| Не открываются банки/Госуслуги | Включить «Настройки → Маршрутизация → Российские сайты напрямую» (по умолчанию включено). |
| Сайты открываются медленно | Выключить IPv6 в настройках Tunnely; выбрать сервер с меньшей задержкой. |
| Не ставится обновление APK («Приложение не установлено») | APK подписан другим ключом. Сборки для клиентов — только с постоянным ключом (ANDROID_BUILD.md). |
| Плитка/виджет открывают приложение вместо подключения | Ещё не выдано разрешение VPN или не добавлен ключ — сделать это один раз в приложении. |

## У владельца серверов

### Как понять причину
«Настройки → Журнал работы» или «О приложении → Проверить соединение и скопировать отчёт». В отчёте для каждого сервера — задержка или причина:
- «ключ не принят сервером (подписка могла истечь)» — сервер оборвал соединение после рукопожатия: ключ (UUID) удалён/отключён в панели;
- «сервер отклонил защищённое подключение» — не совпадают параметры Reality/TLS (pbk, sid, sni);
- «сервер не отвечает (тайм-аут)» / «недоступен из этой сети» — сервер выключен или блокируется в сети пользователя;
- «не удаётся найти адрес сервера» — DNS.

## У разработчика

| Ошибка | Решение |
|---|---|
| `link: github.com/wlynxg/anet: invalid reference to net.zoneCache` | Сборка Xray для Android требует `-ldflags=-checklinkname=0` (есть в скриптах `build_core_android.*`). |
| `[CXX1101] NDK … did not have a source.properties` | Битая загрузка NDK: удалить папку `ndk\<версия>` и поставить заново через sdkmanager. |
| `Could not close incremental caches` (Kotlin) | Параллельные сборки или разные диски: `flutter clean`, `kotlin.incremental=false`. |
| `PathExistsException … flutter_assets` | Две сборки одновременно. Дождаться одной и повторить. |
| PowerShell: `NativeCommandError` на предупреждениях Java | В скриптах для внешних команд `$ErrorActionPreference = "Continue"` + проверка `$LASTEXITCODE`. |
| `gomobile: unsupported platform "$Targets"` | Аргумент `-target=$Targets` в PowerShell нужно брать в кавычки. |
