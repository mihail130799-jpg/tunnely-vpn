# Сборка и установка Android-версии Tunnely

## Готовые файлы
`releases/<версия>/`:

| Файл | Для каких телефонов |
|---|---|
| `Tunnely-<версия>-arm64-v8a.apk` | **почти все телефоны с 2017 года**, отправляйте клиентам его |
| `Tunnely-<версия>-armeabi-v7a.apk` | старые 32-битные телефоны |
| `Tunnely-<версия>-x86_64.apk` | эмуляторы и редкие планшеты на Intel |
| `SHA256SUMS.txt` | контрольные суммы для проверки целостности |

Требуется Android 7.0 (API 24) или новее.

## Установка на телефон
1. Передайте `Tunnely-…-arm64-v8a.apk` на телефон (Telegram, облако, кабель).
2. Откройте файл. Android попросит разрешить установку из этого источника (Telegram, «Файлы» и т. п.) — разрешите.
3. Нажмите «Установить». Google Play Защита может предупредить о неизвестном приложении — «Всё равно установить».
4. Откройте Tunnely → «Из буфера» (предварительно скопируйте ссылку подписки) → нажмите на туннель → разрешите VPN.

## Обновление
Новый APK с той же подписью ставится поверх старого, ключи и подписки сохраняются. Android сам покажет «Обновить».
**Подпись должна быть та же** — иначе Android откажет в установке поверх, и клиентам придётся удалять приложение.

## Ключ подписи (ВАЖНО)
- Ключ: `secrets/android/tunnely-release.jks`, пароль и алиас: `secrets/android/key.properties`. Папка `secrets/` не попадает в git.
- SHA-256 сертификата: `1B:07:E2:46:7B:B7:37:76:A1:25:A8:9B:D3:D4:54:C6:7F:01:BA:D6:CA:8F:F3:52:70:BD:09:FC:BF:C7:B8:64`
- **Сделайте резервную копию обоих файлов** (например, на зашифрованную флешку и в менеджер паролей). Если ключ потерян, выпустить обновление для уже установленных у клиентов приложений будет невозможно.
- Сборщик берёт ключ из `vpn_client/android/key.properties` (копия того же файла) или из переменных окружения `TUNNELY_KEYSTORE_PATH`, `TUNNELY_KEYSTORE_PASSWORD`, `TUNNELY_KEY_ALIAS`, `TUNNELY_KEY_PASSWORD` (для CI).

## Сборка
```powershell
.\scripts\build_android.ps1                # анализ + тесты + release APK
.\scripts\build_android.ps1 -SkipTests
.\scripts\build_android.ps1 -RebuildCore   # пересобрать ядро Xray (Go → AAR) перед сборкой
```
Версия берётся из `vpn_client/pubspec.yaml` (`version: 0.2.0+3`; число после `+` нужно увеличивать при каждом выпуске — Android сравнивает его при обновлении). При разбиении по ABI Flutter добавляет к нему 1000×ABI: для 0.2.0: armeabi-v7a → 1003, arm64-v8a → 2003, x86_64 → 4003.

## Автосборка в GitHub Actions
`.github/workflows/android.yml`: тесты Dart и Go → сборка ядра (`scripts/build_core_android.sh`) → release APK → артефакт с SHA256SUMS.
Для подписанных сборок добавьте секреты репозитория `TUNNELY_KEYSTORE_BASE64` (base64 файла `.jks`), `TUNNELY_KEYSTORE_PASSWORD`, `TUNNELY_KEY_ALIAS`, `TUNNELY_KEY_PASSWORD`. Без них APK подписываются отладочным ключом — раздавать их нельзя.
**Статус:** работает (первый прогон 28.10.2026 — успешно). Без секретов подписи артефакты подписаны отладочным ключом — клиентам раздавать только APK из Releases.

Скрипт проверяет подпись каждого APK (`apksigner verify`) и пишет `SHA256SUMS.txt`.
