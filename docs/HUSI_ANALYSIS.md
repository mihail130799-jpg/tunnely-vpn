# Анализ Husi (Android-референс по указанию владельца)

Источник: github.com/xchacha20-poly1305/husi, ветка `dev`, релиз **v2.3.2** (2026-10-23), скриншоты из `fastlane/metadata`. Просмотрено 2026-10-26.
Скриншоты Husi в репозиторий не копируются.

## Что это
- Наследник SagerNet → NekoBox → AntiNeko → Husi. Позиционируется как «непрофессиональный» набор прокси-инструментов для опытных пользователей.
- Kotlin + Compose Multiplatform (Android и десктоп), 1.9k звёзд, активно развивается.
- **Ядро: sing-box** (`libcore` на Go, `sagernet/sing-box v1.15.0-alpha.12`), собирается через `sagernet/gomobile` в `libcore.aar`. Mihomo не используется. «Clash Mode» на скриншотах — это Clash API, встроенный в sing-box.
- Плагины (mieru, shadowquic и т. д.) — отдельные APK.
- **Лицензия: GPL-3.0-or-later.** Заимствование кода Husi делает наш код GPL-3.0.

## Интерфейс (скриншоты)
1. **Конфигурации:** боковое меню (гамбургер), строка поиска, «добавить файл», «⋮». Карточки профилей: имя, протокол, трафик ↑↓, кнопки «изменить», «поделиться», «удалить», перетаскивание.
2. **Нижняя панель статуса:** скорость ↑/↓ и строка «Connected, tap to check connection» (по нажатию — проверка соединения с замером, например «HTTP handshake took 395ms»). Круглая FAB-кнопка подключения (бумажный самолётик) справа внизу.
3. **Route:** список правил маршрутизации с переключателями (Sniff, Hijack DNS, Bypass ICMP, Block QUIC, Block ADs, правила по geosite).
4. **Dashboard → Stats:** память и горутины ядра, адреса, Clash Mode (Rule / block / direct / global), сетевые интерфейсы.
5. **Dashboard → Connections:** живой список соединений (протокол, IP, домен, приложение-источник с иконкой, трафик), пауза и очистка.
6. **Dashboard → Proxy Set:** группа URLTest с карточками серверов и задержкой в мс, кнопка «⚡» для теста.

## Сильные стороны, полезные для Tunnely
- Надёжная Android-часть: VpnService, foreground-сервис, Quick Settings плитка, per-app proxy, обработка смены сети, перезапуск ядра.
- Проверка соединения по нажатию на статус (реальный HTTP-запрос через туннель, показывает задержку).
- URLTest-группа: автоматический выбор самого быстрого сервера.
- Правила маршрутизации: блокировка рекламы, обход локальных сетей и выбранных стран, блокировка QUIC.
- Диагностика: живые соединения, память ядра — полезно в разделе «Диагностика».

## Что не подходит клиентам Tunnely напрямую
- Интерфейс рассчитан на технарей (Material 3 «по умолчанию», термины sniff / hijack-dns / geosite). Наш утверждённый дизайн — концепция C, простой для клиентов.
- Решение: сложные функции Husi прячем в «Настройки → Расширенные» и «Диагностику», главный экран остаётся по DESIGN_SYSTEM.md.
