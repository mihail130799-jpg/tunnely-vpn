# ADR 0001: VPN-ядро — Xray-core через libXray (вместо sing-box)

Дата: 2026-10-26. Статус: принято (техническое решение).

## Контекст
В ТЗ sing-box указан как предпочтительное ядро, но с оговоркой: если технология не подходит, нужно выбрать обоснованную альтернативу.
Приложение распространяется под собственным брендом Tunnely, в том числе через App Store / TestFlight.

## Проверено (2026-10-26)
| | sing-box | Xray-core |
|---|---|---|
| Последний стабильный релиз | v1.14.4 (2026-10-24) | v26.10.21 (2026-10-21) |
| Лицензия | **GPL-3.0** + запрет использовать имя sing-box в производных работах | **MPL-2.0** (копилефт только на изменённые файлы самого ядра) |
| Обёртка для мобильных | libbox (собирать самим через gomobile, готового AAR/XCFramework в релизах нет) | **libXray** (MIT, активно поддерживается, обновлён 2026-10-23) |
| VLESS Reality | да | да, эталонная реализация (авторы Reality — XTLS) |
| VLESS XHTTP | **нет** | да |
| VLESS Vision | да | да, эталонная реализация |
| Trojan / Shadowsocks / VMess | да | да |
| Hysteria2 / TUIC | да | Hysteria2 нужно перепроверить, TUIC нет (оба опциональны в ТЗ) |
| TUN на Android / iOS | да | да: `proxy/tun` (`tun_android.go`, `tun_darwin.go`, `tun_fd.go` — работа с fd от VpnService / utun) |
| Используется в Happ | нет | да (Happ на Xray) |

## Решение
Ядро — **Xray-core**, встраиваемое через **libXray** (gomobile → `.aar` для Android, `.xcframework` для iOS).
Если встроенный TUN Xray окажется нестабильным на какой-то платформе, запасной вариант — `hev-socks5-tunnel` (MIT) в связке с SOCKS-входом Xray.

## Почему
1. **Лицензия.** GPL-3.0 у sing-box обязывает публиковать исходный код всего приложения под GPL всем получателям. Кроме того, GPL плохо совместима с условиями App Store. MPL-2.0 позволяет оставить код Tunnely закрытым: публиковать нужно только собственные изменения файлов Xray (мы их не меняем).
2. **Совместимость с серверами владельца.** Серверы на VLESS Reality почти наверняка работают на Xray (3x-ui / Marzban / Remnawave). Эталонная реализация даёт максимальную совместимость, включая XHTTP и Vision, которых нет в sing-box (XHTTP).
3. Тот же стек, что у Happ, — это ориентир по функциональности.

## Последствия
- Нужен Go + gomobile + Android NDK (есть) для сборки `.aar`; `.xcframework` собирается только на macOS (CI).
- В «О приложении» указываются лицензии Xray-core (MPL-2.0), libXray (MIT) и ссылка на исходники Xray.
- Формат конфигурации — JSON Xray; парсер ссылок (vless://, trojan://, ss://, vmess://) пишем на Dart и генерируем JSON Xray.
