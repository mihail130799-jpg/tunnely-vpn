# Анализ интерфейса Happ (референс для Tunnely)

Источник: официальные скриншоты Happ — Proxy Utility в App Store (id6504287215) и сайт happ.su, просмотрено 2026-10-26.
Скриншоты Happ в репозиторий **не** сохраняются (чужие материалы). Мы берём только принципы компоновки, без графики, иконок и фирменных элементов.

## Что делает Happ
- Ядро Xray; протоколы VLESS (Reality), VMess, Trojan, Shadowsocks, Socks.
- Своих серверов нет: пользователь добавляет ключи и подписки.
- Платформы: iOS, Android, Windows, macOS, Linux, TV.

## Главный экран (один экран, без нижней навигации)
- **Верхняя панель:** шестерёнка «Настройки» слева, «+» (добавить) справа. Без заголовка.
- **Кнопка подключения:** большая круглая кнопка с иконкой питания, примерно 40% ширины экрана, в верхней половине. Неоморфный светлый стиль, вокруг тонкое кольцо с цветным градиентом.
- **Состояние «Подключено»:** иконка окрашивается в акцентный цвет, под ней надпись «CONNECTED» и таймер `00:00:03` прямо внутри кнопки.
- **Пустое состояние:** текст-подсказка «нужно добавить сервер или подписку» и две крупные кнопки-«пилюли»: «Clipboard» и «QR-Code». Это и есть самый короткий путь импорта.
- **Список серверов прямо под кнопкой:** карточка с закруглёнными углами.
  - Шапка группы: название подписки (домен), дата обновления, кнопка сворачивания, иконки «обновить», «тест задержки», «…».
  - Строка сервера: флаг страны, название, протокол серым мелким текстом, шеврон «>».
  - Активный сервер: радио-точка слева и подсвеченный фон строки.
- Ссылка «Hide everything» (скрыть список).

## Подписка (модальный лист)
- «Subscription URL», «Cancel» / «Done», поля Title и URL.
- Переключатели «Hidden servers settings» и «Encrypted subscription».

## Стиль
- Светлая тема: фон почти белый `#F2F2F4`, мягкие тени, крупные скругления (~16–20 px).
- Акцент фиолетово-синий (≈ `#5F5FAF` в маркетинге), в интерфейсе мало цвета.
- Шрифт: системный (SF / Roboto), полужирные названия, серые подписи.
- Минимум информации: в базовом виде нет статистики трафика и карты.

## Выводы для Tunnely
1. Берём: однoэкранную схему «кнопка сверху, список серверов снизу», импорт за 1 тап (буфер / QR) в пустом состоянии, группировку по подпискам, таймер внутри кнопки.
2. Делаем по-своему: фирменная кнопка-«туннель» из концентрических арок по мотивам логотипа Tunnely (вместо неоморфной кнопки питания), сине-голубая палитра, анимация «свет в конце туннеля» при подключении, компактная строка статистики (скорость и трафик), которую Happ не показывает.
3. Не копируем: иконки Happ, их градиентное кольцо, маркетинговую графику, тексты.
