## Ручные проверки на эмуляторе (Pixel 7, Android 15, x86_64, release 0.1.1)
| Проверка | Как | Результат |
|---|---|---|
| Установка начисто и обновлением поверх | `adb install` / `install -r` | ✅ данные сохраняются |
| Импорт подписки владельца | `tunnely://import?url=…` | ✅ |
| Серверы владельца Frankfurt / Finland | HTTP к Cloudflare `/cdn-cgi/trace` из оболочки эмулятора | ✅ `loc=DE` / `loc=FI` |
| DNS через туннель | запрос к `example.com` по имени | ✅ HTTP 200 |
| Смена Wi-Fi ↔ мобильная сеть при включённом VPN | `svc wifi disable/enable` | ✅ трафик идёт через сервер в обоих случаях |
| Плитка в шторке | `cmd statusbar click-tile` при открытой шторке, 4 нажатия | ✅ вкл/выкл/вкл/выкл |
| Виджет | добавлен на рабочий стол, нажатие | ✅ включает и выключает VPN без открытия приложения, статус и сервер обновляются |
| Скорость | загрузка большого файла через VPN | ✅ приложение показывало ~1,4 МБ/с при фактических ~1,5 МБ/с |
| Импорт из файла | системный выбор файла → `tunnely_keys.txt` | ✅ «Сервер добавлен» |
| Неработающий сервер | сервер с отказом Reality | ✅ «Сервер не отвечает», «нет связи» |
| Ошибка подписки | недоступный хост | ✅ «Нет связи с сервером подписки» |

Метод проверки маршрута: `printf "GET /cdn-cgi/trace …" | toybox nc 104.16.123.96 80` → поле `loc=` показывает страну выхода.

## Не проверено
- Физический телефон (ждём проверки владельцем).
- QR-сканер (у эмулятора нет камеры).
- Trojan, SS, VMess, Hysteria2, TUIC, XHTTP/WS/gRPC на живых серверах.
- Долгая работа в фоне и поведение при агрессивной экономии батареи (Xiaomi, Huawei и т. п.).
- GitHub Actions (репозиторий не опубликован).
