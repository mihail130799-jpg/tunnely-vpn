# Безопасность и приватность

## Данные пользователя
- Ключи (UUID, пароли, публичные ключи Reality) и ссылки подписок хранятся **только на устройстве**:
  - список серверов и подписок — `flutter_secure_storage` (шифрование ключом Android Keystore);
  - конфиг для VPN-сервиса — файл в `noBackupFilesDir`, AES-256-GCM, ключ в Android Keystore (`ConfigStore`).
- Резервное копирование данных приложения в облако и перенос на новое устройство отключены (`allowBackup=false`, `data_extraction_rules.xml`).
- Нет аналитики, рекламы, отправки логов. Сетевые запросы приложения: загрузка подписок по ссылкам пользователя, проверка серверов (HTTP-запрос к `gstatic.com/generate_204` через сервер, средствами ядра) и проверка обновлений раз в сутки (`api.github.com/repos/mihail130799-jpg/tunnely-vpn/releases/latest`, без идентификаторов пользователя).
- Список установленных приложений читается только на устройстве — для экрана «Приложения без VPN» и исключения их из туннеля; никуда не отправляется.
- Ключи не попадают в сообщения об ошибках и в отчёт диагностики (версия, режимы, имена серверов, задержки и причины ошибок, журнал).
- Журнал работы (приложение, VPN-служба, ядро) хранится только на устройстве и не содержит ключей, UUID, паролей и ссылок подписок. В подробном режиме ядро записывает адреса посещаемых сайтов — включается пользователем вручную.

## Сеть
- TLS-сертификаты подписок проверяются всегда; отключить проверку нельзя.
- Флаг `allowInsecure`/`insecure` из ссылки владельца переносится в конфиг как есть (это решение владельца сервера).
- Собственный трафик приложения исключён из туннеля, чтобы не зацикливаться.

## Обновления
- APK скачивается только из релизов публичного репозитория по HTTPS, хеш SHA-256 сверяется с `SHA256SUMS.txt` того же релиза; при несовпадении файл удаляется.
- Установку выполняет системный установщик Android с подтверждением пользователя; он же проверяет, что APK подписан тем же ключом, что и установленное приложение (иначе обновление невозможно).
- APK передаётся установщику через `FileProvider` (только каталог `cache/updates`).

## Разрешения Android
| Разрешение | Зачем |
|---|---|
| `BIND_VPN_SERVICE` (через системный диалог) | создание VPN |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE` | работа VPN в фоне |
| `POST_NOTIFICATIONS` | уведомление «Защищено» с кнопкой «Отключить» |
| `INTERNET`, `ACCESS_NETWORK_STATE`, `CHANGE_NETWORK_STATE` | сеть и отслеживание её смены |
| `CAMERA` (из плагина QR) | только при сканировании QR-кода |
| `REQUEST_INSTALL_PACKAGES` | установка обновления APK с подтверждением пользователя |
| `<queries>` LAUNCHER | список приложений для «Приложения без VPN» (только приложения с ярлыком) |

## Секреты разработки
- `secrets/` (ключ подписи, тестовая подписка) и `vpn_client/android/key.properties` исключены из git.
- Пароль ключа подписи сгенерирован случайно и нигде не печатался. **Нужна резервная копия `secrets/android/`.**
- В CI ключ передаётся только через GitHub Secrets (`.github/workflows/android.yml`).
- Тестовые ключи в автотестах — синтетические (`11111111-2222-…`, `example.com`).
